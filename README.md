# LP5 Live Telemetry

LP5 Live Telemetry is a free, read-only desktop telemetry monitor for the LaserPecker LP5, created by Extrusion Therapy.

## Download

Download the current Apple-silicon macOS and 64-bit Windows installers from the [latest GitHub Release](../../releases/latest).

LaserPecker Design Space must remain open and connected to the LP5 while a job is running. LP5 Live Telemetry reads the telemetry records created by LaserPecker Design Space and presents the available machine information in a dedicated window. It does not control the laser or change machine settings.
