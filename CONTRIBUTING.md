# Contributing to LP5 Live Telemetry

Discuss substantial changes in an [issue](https://github.com/rdcstout/lp5-live-telemetry/issues) before implementation. Keep pull requests focused and preserve the read-only monitoring behavior.

For bug reports, include the app version, operating system, a minimal reproduction, and expected versus observed behavior. Remove personal paths, project details, identifiers, and credentials from screenshots or logs. Use the private route in [SECURITY.md](SECURITY.md) for suspected vulnerabilities.

Follow [DEVELOPMENT.md](DEVELOPMENT.md) for setup and [validation](DEVELOPMENT.md#validation). Include relevant check results and identify manual or unavailable checks accurately. Read the [automated-checks section](DEVELOPMENT.md#automated-checks) before pushing updates; avoid repeated catch-up pushes or unnecessary CI runs.

Passing checks does not guarantee acceptance or a release. The maintainer controls merging and publication; do not enable auto-merge or publish on the maintainer's behalf. No open-source license is currently specified; discuss licensing with the maintainer before substantial contributions.
