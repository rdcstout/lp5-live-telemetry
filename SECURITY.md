# Security policy

Security fixes target the latest published stable release, currently 1.0.3. Older releases should be upgraded; backports are not promised. Reports about unreleased source should identify the affected commit.

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/rdcstout/lp5-live-telemetry/security/advisories/new). Do not put vulnerability details, credentials, personal LDS logs, or project data in public issues or pull requests.

Include the affected version or commit, operating system, a minimal safe reproduction, expected impact, and relevant source locations. Redact personal information. Do not test against someone else's device or data.

Reports are handled on a best-effort basis. No response, fix, disclosure deadline, bounty, or reporter-credit commitment is promised. Ordinary bugs without a security impact belong in the [issue tracker](https://github.com/rdcstout/lp5-live-telemetry/issues).
